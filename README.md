# Site Dra. Danielle Machado

Landing page responsiva em português com atuação profissional, mentorias e contatos oficiais.

## Abrir e editar

Abra `index.html` no navegador. Não há dependências ou etapa de build. O conteúdo e os estilos estão nesse arquivo; as imagens utilizadas estão em `assets/`.

As fontes são carregadas pelo Google Fonts, com alternativas locais em caso de indisponibilidade.

## Hospedagem

Publique a raiz em uma hospedagem estática. Para usar GitHub Pages, configure a branch `main` e pasta `/ (root)` nas configurações do repositório.

Versão hospedada: https://dra-danielle-machado.ailtonjrsantossilva1.chatgpt.site/

## Recursos

- Layout para celular e computador.
- Retrato transparente com legenda na altura dos joelhos.
- Logotipo com fundo transparente.
- Links oficiais de atendimento, mentorias, Instagram e localização.
- Perguntas frequentes expansíveis.
